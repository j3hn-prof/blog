# Writing a website as someone who hated webdev

For the longest time, I had a *very* negative prespective on web development. I viewed the skill as boring, easy, and not intelectually engaging in the slightest. As an undergraduate of computer engineering, I must have felt some type of superiority, writing all my code in **good** languages like C, C++, and Nix. The thought of having to deal with an *interpreter* or a *runtime* gave me the impression that languages like Python and--more notably--Typescript were too high level to be worth knowing.
